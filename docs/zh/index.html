Wy Store

熟悉的俄罗斯应用，没人盯着你装什么

与 RuStore 里相同的应用，外加 GitHub 上的发布版。Wy Store 自己下载、自己安装， 走 Android 系统自带的安装器。不需要账号 —— RuStore 的不要，别家的也不要。

下载 APK

Android 9.0 及以上 · 约 9 MB · 开源，MIT 许可

第二个来源：GitHub

RuStore 里没有的开源项目发布版 —— Droid-ify、Neo Store、Syncthing、Ente Photos、 Stratum 等等，直接从各自的 releases 安装，每个条目都标出来源。

任何公开仓库都可以用链接添加。发布版按规则挑选：nightly 标签、以及没有可用 APK 的发布版 会被跳过。目录本身面向俄罗斯的用户，所以其中大部分是俄语；界面支持上方菜单中的所有语言。

与 RuStore 里相同的文件

Wy Store 装的，正是开发者自己发布到 RuStore 的那些应用 —— 没有改动，中间没有经手人。 文件来自 RuStore 的服务器，安装前 Wy Store 会核对它就是原件：开发者签名和版本 与商店条目一致。

页面上有版本、大小、所需的 Android 版本、评分和下载次数，和 RuStore 一样。

在后台更新

Wy Store 按计划检查更新，并自己把它们下载下来。再往后就看手机了：有些 Android 版本 不问一声就装上，有些则要你确认。我们尽量把需要你动手的部分压到最小，但这没法在每台设备上 都保证。

通常是这样
Android 12 及以上一般不问 —— 对 Wy Store 自己装的应用而言
Android 9、10、11系统会请你确认，任何商店都一样
首次安装总是要确认
有 root支持：一切在后台静默安装，没有通知 —— 在设置里开启

我的应用

所有已装的应用，按来源筛选：Wy Store、GitHub、RuStore。由 Wy Store 自己安装或 更新过的排在前面。更新和卸载都在同一个列表里，“检查并安装”一下全办完。

来自 Google Play 的应用不会被动，除非你为某个具体应用打开它。

  • 没有账号。
  • 没有统计。
  • 没有广告。
  • 不要你的数据。

Wy Store 不收集关于你的任何东西，也不往任何地方发送。应用只与 RuStore 和 GitHub 通信，为的是目录和文件。其余一切都留在手机上。 完整的隐私政策。

安装

下载 APK

  1. 打开下载好的 wystore.apk。
  2. Android 会就“允许从此来源安装”问一次。
  3. 此后 Wy Store 自己更新自己 —— 它盯着仓库里的发布版。

Wy Store 的每个版本都用同一个开发者密钥签名，Android 不会让更新把它换成别人的构建。 如何手动校验签名，写在安全说明里。
