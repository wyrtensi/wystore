# Root для Wy Store в KernelSU

Root в Wy Store не обязателен и по умолчанию выключен. Каталог, поиск и страницы приложений
работают без него и никогда его не запрашивают. Как root используется в целом — в разделе «Root»
[README](README.md#root).

Wy Store вызывает `su` в таких случаях:

- по кнопке «Проверить Root»;
- при запуске, если включены «Тихая root-установка» или «Тихое root-удаление»: иначе переключатель
  остался бы включённым после того, как права отозвали;
- в фоновой проверке обновлений, но только когда выключено «Скачивать обновления сразу» и включено
  «Скачивать обновления в фоне (root)»;
- при установке или удалении, если включён соответствующий переключатель.

Если доступ выдан не навсегда, KernelSU может спрашивать при каждом таком вызове.

## Один раз включить совместимость

В KernelSU Manager откройте настройки и включите **SU Compatibility Mode** / **Перенаправление su binary**. В этой версии KernelSU переключатель также называется `su_compat`.

Это разрешает KernelSU перенаправлять `/system/bin/su` только для приложений, которым вы отдельно дали права. Сам по себе переключатель не даёт Wy Store root.

Wy Store ищет `su` в `PATH`, `/system/bin`, `/system/xbin`, `/sbin`, `/su/bin` и `/debug_ramdisk`. Root считается выданным, только если `id` сообщает uid 0.

Если нужен вариант через ADB:

```powershell
adb shell /data/adb/ksu/bin/ksud feature set su_compat 1
adb shell /data/adb/ksu/bin/ksud feature get su_compat
```

В результате должна быть строка `Status: enabled`.

## Выдать доступ Wy Store

1. Откройте Wy Store → **Настройки** → **Центр разрешений** → **«Проверить Root»**.
2. В запросе KernelSU выберите разрешение для **Wy Store** (`app.wystore`).
3. Карточка Root-доступа должна показать «Доступен». Если показывает «Не выдан» — доступ не выдан или его отклонили.

Если окно не появилось, откройте KernelSU Manager → Superuser / App Profile, найдите Wy Store и выдайте ему root вручную. Затем полностью закройте Wy Store, откройте снова и повторите «Проверить Root».

## Переключатели

В настройках, в группе «Фоновые обновления». Работают, только пока root выдан.

- **Тихая root-установка** — первые установки и обновления, из RuStore и с GitHub, идут через `pm` от root без окна Android. Wy Store записывается установщиком приложения, а на Android 14 и новее — и владельцем обновлений, так же как при установке через диалог.
- **Тихое root-удаление** — выключено по умолчанию. Кнопка «Удалить» удаляет приложение сразу, без подтверждения, вместе с его данными. Если root в этот момент не выдан, открывается обычное окно удаления Android.
- **Скачивать обновления в фоне (root)** — фоновая проверка скачивает обновления, даже когда «Скачивать обновления сразу» выключено.

С включённой тихой установкой фоновая проверка сама находит обновление, скачивает и ставит его, пока Wy Store закрыт.

## Безопасная настройка профиля

- Оставьте UID 0 и стандартный SELinux-профиль KernelSU: установщик использует `pm` и требует полный root только на время команды.
- Не включайте root-переключатели для фона и удаления, пока не убедитесь, что ручные установки работают. Все они выключены по умолчанию.
- Если root отозвать, «Проверить Root» покажет «Не выдан», тихая установка выключится, и установка вернётся к окну Android.
- После удаления Wy Store или установки сборки с другой подписью разрешение KernelSU нужно выдать заново.

## Проверка установки

Откройте карточку приложения и нажмите «Установить». Wy Store проверит package name, versionCode, полный набор split APK и совпадение сертификата с уже установленным приложением. Для пакета, который уже управляется другим магазином, программа покажет отдельное предупреждение; для Google Play сначала требуется включить «Форсировать Wy Store» в Библиотеке.
