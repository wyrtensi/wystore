# Root для Wy Store в KernelSU

Wy Store использует штатный механизм KernelSU `su` только в момент установки или обновления APK. Он не просит root при открытии каталога, просмотре карточек и фоновой проверке обновлений.

## Один раз включить совместимость

В KernelSU Manager откройте настройки и включите **SU Compatibility Mode** / **Перенаправление su binary**. В этой версии KernelSU переключатель также называется `su_compat`.

Это разрешает KernelSU перенаправлять `/system/bin/su` только для приложений, которым вы отдельно дали права. Сам по себе переключатель не даёт Wy Store root.

Если нужен вариант через ADB:

```powershell
adb shell /data/adb/ksu/bin/ksud feature set su_compat 1
adb shell /data/adb/ksu/bin/ksud feature get su_compat
```

В результате должна быть строка `Status: enabled`.

## Выдать доступ Wy Store

1. Откройте Wy Store → **Настройки** → **Проверить / выдать root**.
2. В запросе KernelSU выберите разрешение для **Wy Store** (`dev.wystore`).
3. Вернитесь в Wy Store и повторите проверку. Статус должен стать `Root: доступен`.

Если окно не появилось, откройте KernelSU Manager → Superuser / App Profile, найдите Wy Store и выдайте ему root вручную. Затем полностью закройте Wy Store и откройте снова.

## Безопасная настройка профиля

- Оставьте UID 0 и стандартный SELinux-профиль KernelSU: установщик использует `pm install` и требует полный root только на время команды.
- Не включайте root в фоне, пока не убедитесь, что ручные установки работают. В Wy Store этот переключатель выключен по умолчанию.
- После удаления Wy Store или установки сборки с другой подписью разрешение KernelSU нужно выдать заново.

## Проверка установки

Откройте карточку приложения и нажмите «Установить». Wy Store проверит package name, versionCode, полный набор split APK и совпадение сертификата с уже установленным приложением. Для пакета, который уже управляется другим магазином, программа покажет отдельное предупреждение; для Google Play сначала требуется включить «Форсировать Wy Store» в Библиотеке.
